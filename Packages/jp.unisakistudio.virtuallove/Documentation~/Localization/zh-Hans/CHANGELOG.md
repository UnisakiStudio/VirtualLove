# 更新记录

## [3.2.0] - 尚未发布

### 新增

- Inspector、安装菜单、许可证提示、收录姿势名和生成的VRChat菜单现支持30种显示语言。
- 统一了Inspector和游戏内菜单的语言选择。初始使用计算机语言，同一OS用户的其他项目也会使用最后的选择。
- 支持以所选语言打开README和更新记录。
- 为22种收录姿势的显示名和5个分类菜单的名称准备了各语言版本。
- 支持Unisaki Posing System 3.2.0。

### 兼容性

- 保留虚拟形象的现有设置、自定义名称、资源引用、参数标识符和许可证保存方式。

## [3.1.0] - 2026-11-07

- 新增拍照模式。可以将虚拟形象向前移动或旋转，调整到便于拍照的位置。还可以选择将位置和朝向同步给其他人，以及在拍照期间显示自己的头部。
- 新增“地面高度”。可上下移动包含头部在内的整个身体，与保持头部位置、移动脚部一侧的“脚部高度”区分使用。
- 新增呼吸动画。可按姿势分类选择强度，还可以添加在游戏内暂停或恢复呼吸的菜单。也可以使用抑制VRChat默认待机摇摆的设置。
- 新增一项设置，用于减轻解除头部固定后因头部朝向不同而造成的姿势变形。
- 支持虚拟形象专属修正和防止膝盖反折。可修正与制作基准Anon之间的关节差异，并根据虚拟形象调整姿势。
- 现在可以在Inspector中选择所需功能，并确认参数用量。
- 可在姿势列表中使用搜索、批量添加、顺序调整，以及Scene中的简易预览。
- 可从虚拟形象的右键菜单通过“Unisaki Studio > 添加Virtual Love（男性）／添加Virtual Love（女性）”安装。添加后的功能在Inspector中选择。
- 需要Unisaki Posing System 3.1.0。
