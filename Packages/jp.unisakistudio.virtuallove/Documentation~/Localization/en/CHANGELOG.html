Changelog

[3.2.0] - Unreleased

Added

  • The Inspector, the add menus, the license notices, the included pose names and the generated VRChat menus can now be displayed in 30 languages.
  • Unified the language selection for the Inspector and the in-game menus. It starts with your computer's language, and your last choice is also used in other projects of the same OS user.
  • The README and the changelog can now be opened in the selected language.
  • Prepared display names for the 22 included poses and names for the 5 category menus in each language.
  • Added support for Unisaki Posing System 3.2.0.

Compatibility

  • Existing avatar settings, custom names, asset references, parameter identifiers and license storage are preserved.

[3.1.0] - 2026-11-07

  • Added Photo Mode. Move the avatar forward and rotate it to a position that is easy to photograph. You can also choose to sync the position and direction to other people and to keep your own head visible while photographing.
  • Added Floor Height. It moves the whole body, including the head, up and down, separately from Foot Height, which moves the feet side while keeping the head position.
  • Added breathing motion. Choose its strength for each posture category, and add a menu to stop and resume breathing in-game. A setting to suppress VRChat's default idle sway is also available.
  • Added a setting that reduces pose distortion caused by a different neck orientation when head lock is released.
  • Added support for avatar correction and reverse knee bend prevention. They correct joint differences from Anon, the reference avatar used for production, and adjust the poses to your avatar.
  • You can now choose the features you need in the Inspector and check parameter usage.
  • Search, batch adding and reordering in the pose list and a quick Scene preview are available.
  • Install it from the avatar's right-click menu with Unisaki Studio > Add Virtual Love (Male) / (Female). Choose the features in the Inspector after adding it.
  • Unisaki Posing System 3.1.0 is required.
