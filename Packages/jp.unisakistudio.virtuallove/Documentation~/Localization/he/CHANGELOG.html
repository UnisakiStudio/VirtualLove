יומן שינויים

[3.2.0] - טרם שוחרר

נוסף

  • ה-Inspector, תפריטי ההוספה, הודעות הרישיון, שמות התנוחות הכלולות ותפריטי VRChat שנוצרים מוצגים כעת ב-30 שפות.
  • בחירת השפה של ה-Inspector ושל תפריטי המשחק אוחדה. ברירת המחדל היא שפת המחשב, והבחירה האחרונה משמשת גם פרויקטים אחרים של אותו משתמש במערכת ההפעלה.
  • אפשר כעת לפתוח את ה-README ואת יומן השינויים בשפה שנבחרה.
  • הוכנו בכל שפה שמות תצוגה ל-22 התנוחות הכלולות ושמות ל-5 תפריטי הקטגוריות.
  • נוספה תמיכה ב-Unisaki Posing System 3.2.0.

תאימות

  • נשמרים הגדרות האווטאר הקיימות, שמות אישיים, הפניות לנכסים, מזהי פרמטרים ואופן אחסון הרישיונות.

[3.1.0] - 2026-11-07

  • נוסף מצב צילום. אפשר להזיז את האווטאר קדימה ולסובב אותו למיקום שנוח לצלם. אפשר גם לבחור לסנכרן את המיקום והכיוון לאחרים ולהשאיר את הראש שלכם גלוי בזמן הצילום.
  • נוסף גובה רצפה. הוא מזיז את כל הגוף, כולל הראש, למעלה ולמטה, בנפרד מגובה כפות רגליים, שמזיז את צד הרגליים תוך שמירה על מיקום הראש.
  • נוספה תנועת נשימה. אפשר לבחור את עוצמתה לכל סוג יציבה, ולהוסיף תפריט לעצירה ולחידוש של הנשימה בתוך המשחק. זמינה גם הגדרה שמרסנת את תנודות ההמתנה הרגילות של VRChat.
  • נוספה הגדרה שמצמצמת עיוות תנוחה הנגרם מהבדל בכיוון הראש בעת שחרור נעילת ראש.
  • נוספה תמיכה בתיקון ייחודי לאווטאר ובמניעת כיפוף ברכיים לאחור. הם מתקנים הבדלי מפרקים ביחס ל-Anon, אווטאר הייחוס ששימש ביצירה, ומתאימים את התנוחות לאווטאר שלכם.
  • אפשר כעת לבחור ב-Inspector את התכונות הדרושות ולבדוק את השימוש בפרמטרים.
  • ברשימת התנוחות זמינים חיפוש, הוספה מרוכזת וסידור, וכן תצוגה מקדימה מהירה ב-Scene.
  • ההתקנה נעשית מתפריט הלחיצה הימנית של האווטאר, דרך Unisaki Studio > הוספת Virtual Love (גבר) או Unisaki Studio > הוספת Virtual Love (אישה). את התכונות בוחרים ב-Inspector לאחר ההוספה.
  • נדרש Unisaki Posing System 3.1.0.
