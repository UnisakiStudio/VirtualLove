변경 내역

[3.2.0] - 미출시

추가

  • Inspector, 추가 메뉴, 라이선스 안내, 수록 포즈 이름, 생성되는 VRChat 메뉴를 30개 언어로 표시할 수 있도록 했습니다.
  • Inspector와 게임 내 메뉴의 언어 선택을 통합했습니다. 기본값은 컴퓨터의 언어를 사용하고 마지막 선택을 같은 OS 사용자의 다른 프로젝트에서도 재사용합니다.
  • README와 변경 내역을 선택한 언어로 열 수 있게 했습니다.
  • 수록 포즈 22종의 표시 이름과 5개 분류 메뉴의 이름을 각 언어로 준비했습니다.
  • Unisaki Posing System 3.2.0을 지원합니다.

호환성

  • 기존 아바타 설정, 자체 이름, 에셋 참조, 파라미터 식별자, 라이선스 저장 방식은 유지합니다.

[3.1.0] - 2026-11-07

  • 촬영 모드를 추가했습니다. 아바타를 앞쪽으로 옮기거나 회전시켜 촬영하기 쉬운 위치로 조절할 수 있습니다. 다른 사람에게 위치·방향을 동기화하거나 촬영 중 자신의 머리를 표시하는 설정도 선택할 수 있습니다.
  • 바닥 높이를 추가했습니다. 머리를 포함한 몸 전체를 위아래로 이동할 수 있으며, 머리 위치를 유지한 채 발 쪽을 움직이는 발 높이와 구분해 사용할 수 있습니다.
  • 호흡 애니메이션을 추가했습니다. 자세 분류별로 강도를 선택할 수 있고, 게임 안에서 호흡을 멈추거나 다시 시작하는 메뉴도 추가할 수 있습니다. VRChat 기본 대기 흔들림을 줄이는 설정도 사용할 수 있습니다.
  • 머리 고정을 해제했을 때 머리 방향 차이로 자세가 무너지는 것을 줄이는 설정을 추가했습니다.
  • 아바타별 보정과 무릎 역꺾임 방지를 지원합니다. 제작 기준인 Anon과의 관절 차이를 보정하여 아바타에 맞게 자세를 조정할 수 있습니다.
  • 필요한 기능을 Inspector에서 선택하고 파라미터 사용량을 확인할 수 있게 되었습니다.
  • 포즈 목록에서 검색, 일괄 추가, 정렬, Scene 간단 미리보기를 사용할 수 있습니다.
  • 아바타의 우클릭 메뉴에서 Unisaki Studio > Virtual Love(남성) 추가 / Virtual Love(여성) 추가로 적용할 수 있습니다. 추가한 뒤의 기능은 Inspector에서 선택합니다.
  • Unisaki Posing System 3.1.0이 필요합니다.
