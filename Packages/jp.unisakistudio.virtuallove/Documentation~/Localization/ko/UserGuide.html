Virtual Love

3점 트래킹이나 데스크톱에서 상대와 짝을 이루는 자세를 즐길 수 있는 VRChat 아바타용 도구입니다. 남성용과 여성용 각 22종, 총 44종의 포즈를 제공합니다. I자 밸런스와 Jack-O 챌린지도 할 수 있습니다.

이 README는 개발 중인 v3.2.0용입니다. 정식 출시일은 정해지지 않았습니다. 설치된 버전은 Inspector 상단에서 확인할 수 있습니다.

표시 언어와 오프라인 문서

Inspector 최상단의 Language / 言語에서 표시 언어를 선택합니다. 하나의 선택이 Inspector와 생성되는 VRChat 메뉴에 모두 적용됩니다. 게임 내 표시 언어를 바꾸려면 아바타를 다시 업로드하세요.

선택한 언어가 없으면 컴퓨터의 언어를 사용하고, 지원하지 않는 언어이면 영어를 사용합니다. Windows·macOS·Linux를 지원합니다. 마지막으로 선택한 언어를 EditorPrefs에 저장하여 이 컴퓨터의 같은 OS 사용자에 속한 다른 프로젝트에서도 사용합니다. 모든 포즈 도구와 아바타는 같은 언어를 사용합니다. 어느 도구의 Inspector에서 변경하든 공통 설정에 반영되며, 아바타별 언어 선택은 사용하지 않습니다. 다른 컴퓨터에는 동기화하지 않습니다. 라이선스 저장 방식은 변경하지 않습니다. 저장된 언어가 없을 때 최초 설치 확인에만 언어 버튼을 표시합니다. 이후에는 Inspector에서 언어를 변경합니다.

README와 변경 내역은 동봉된 언어 목록에서 선택할 수 있습니다. Inspector의 사용 설명서와 변경 내역도 선택한 언어를 따릅니다. 수록 포즈의 이름과 게임 내 메뉴의 분류 이름도 선택한 언어로 표시합니다. 이용 약관은 기존처럼 일본어판을 동봉합니다.

설치 방법

  1. 구매 파일에 동봉된 VirtualLove_Boy.unitypackage 또는 VirtualLove_Girl.unitypackage를 Unity로 가져옵니다.
  2. 패키지 배포처를 등록한 뒤에는 VCC나 ALCOM에서 사용할 프로젝트에 Virtual Love를 추가할 수 있습니다. Unisaki Posing System 3.2.0이 필요합니다.
  3. Hierarchy에서 적용할 아바타를 우클릭하고 Unisaki Studio > Virtual Love(남성) 추가 또는 Unisaki Studio > Virtual Love(여성) 추가를 선택합니다.
  4. 아바타 내부에 추가된 三点だいしゅき(男) 또는 三点だいしゅき(女)를 선택하고 Inspector에서 사용할 기능과 포즈를 설정합니다.
  5. 미리보기로 자세를 확인한 뒤 일반적인 방법으로 아바타를 업로드합니다.

필요 환경은 Unity 2022.3, VRChat Avatars SDK 3.10.4 이상, Modular Avatar 1.x의 1.15.1 이상, NDMF 1.x의 1.14.0 이상입니다. VCC·ALCOM에서 필요한 패키지도 함께 업데이트하세요.

이전 버전에서 업데이트할 때

이 상품과 Unisaki Posing System을 함께 업데이트합니다. 이미 배치된 도구 설정은 유지됩니다. Inspector에서 사용할 기능과 ExpressionParameters 사용량을 확인하고, 프리빌드를 썼다면 프리빌드 업데이트를 누른 뒤 다시 업로드하세요.

게임 내 기본 조작

Expressions 메뉴를 열고 Virtual Love의 포즈를 선택합니다. 남성과 여성이 짝을 이루는 포즈를 고르고 상대와 위치·방향을 맞추세요.

머리·팔·발 고정을 전환하여 트래킹을 따라가게 할 부위를 조절할 수 있습니다. 발 고정을 사용하면 발 쪽 자세를 유지한 채 머리를 움직일 수 있습니다. 포즈의 좌우나 높이를 조절하려면 Unity에서 해당 기능을 미리 켜 두세요.

촬영 모드

자신의 아바타를 보이는 위치로 옮기고 방향을 조절하여 촬영할 수 있습니다.

  1. Unity에서 기능 > 메뉴 기능 > 촬영 모드를 켭니다.
  2. VRChat에서 촬영 모드를 열고 자세 선택에서 사용할 포즈를 고릅니다.
  3. 거리로 아바타를 앞쪽 최대 3m까지 이동합니다. 거리가 0보다 크면 아바타가 자신을 바라봅니다.
  4. 방향으로 회전하고, 위치가 정해지면 필요에 따라 발 고정을 켭니다. 시작할 때 자동으로 발이 고정되지 않으므로 고정 전에 위치를 조절할 수 있습니다.
  5. 촬영이 끝나면 촬영 종료를 누릅니다. 거리와 방향이 원래대로 돌아가고 발 고정이 해제됩니다.

메뉴에 제스처 끄기를 추가했다면 촬영 모드 안에서도 손 모양을 바꿀 수 있습니다.

자신의 화면에서만 위치와 방향을 바꿀 때는 촬영 모드의 동기화 파라미터를 사용하지 않습니다. 다른 사람에게도 같은 위치와 방향을 보이려면 Unity에서 기능 > 편의 기능 > 촬영 모드 동기화를 켜세요.

자신의 머리가 가까워지면 사라져 촬영하기 어렵다면 촬영 모드에서 머리 표시 유지를 켜세요. 촬영 중 자신의 화면에 적용되며 종료하면 평소 표시로 돌아갑니다.

발 높이와 바닥 높이

Unity의 기능 > 메뉴 기능에서 사용할 항목을 켜면 VRChat의 설정 메뉴에 추가됩니다.

  • 발 높이: 머리 위치를 유지하면서 발 쪽 높이를 조절합니다. 발이 바닥에 묻히거나 뜰 때, 상대와 높이를 맞추고 싶을 때 사용합니다.
  • 바닥 높이: 머리를 포함한 몸 전체를 위아래로 이동합니다. 50%가 원래 높이, 0%가 3m 아래, 100%가 3m 위입니다. 원래대로 되돌리려면 50% 부근으로 맞추세요.

촬영 모드와 함께 사용하면 아바타의 높이·거리·방향을 조절할 수 있습니다. 촬영 모드의 이동·회전과 바닥 높이는 포즈를 선택하지 않았을 때의 기본 모션과 자체 모션도 보정합니다. VRChat 안에서의 시점과 기본 모션을 교체한 뒤의 동작은 실제 환경에서 확인하세요.

좌우 반전과 제스처 끄기

  • 좌우 반전: 기능 > 메뉴 기능 > 좌우 반전을 켜고 VRChat 메뉴에서 포즈의 좌우를 바꿉니다.
  • 제스처 끄기: 기능 > 메뉴 기능 > 제스처 끄기를 켭니다. VRChat에서 활성화하면 컨트롤러를 쥐어도 포즈에 설정된 손가락 모양을 유지할 수 있습니다.

호흡

  1. 기능 > 편의 기능 > 호흡 애니메이션 사용을 켭니다.
  2. 설정 열기에서 자세 분류별로 없음·약·중·강·빠름·사용자 지정을 선택합니다. Virtual Love의 자세에 해당하는 분류에서 강도를 조절하세요. 사용자 지정에서는 직접 준비한 호흡 애니메이션을 지정할 수 있습니다.
  3. 게임 안에서도 호흡을 멈추거나 다시 시작하려면 기능 > 메뉴 기능 > 호흡도 켭니다. VRChat에서는 호흡으로 ON/OFF를 전환합니다.

VRChat 기본 대기 흔들림 끄기를 켜면 대기 중 자동으로 들어가는 기본 몸 흔들림을 줄일 수 있습니다. 포즈 도구에서 설정한 호흡은 그대로 사용할 수 있습니다.

머리 방향에 의한 포즈 변형 줄이기

기능 > 편의 기능 > 머리 회전에 의한 포즈 변형 줄이기를 켭니다. 머리 고정을 해제했을 때 원래 포즈와 머리 방향이 달라 몸의 자세가 무너지는 경우에 사용합니다.

뒤척이기

뒤척이기는 해당하는 누운 자세와 옆으로 눕는 애니메이션을 준비하여 사용하는 기능입니다.

  1. 기능 > 메뉴 기능 > 뒤척이기를 켭니다.
  2. 포즈에서 사용할 자세의 상세를 열고 뒤척이기 사용을 켭니다.
  3. 뒤척이기용 옆으로 누운 포즈에 해당하는 애니메이션을 지정하고, 필요하면 접지 보정 강도를 조절합니다.
  4. VRChat에서 해당 자세를 선택하고 머리 고정을 해제한 뒤 뒤척이기를 켭니다. 머리를 좌우로 기울이면 몸을 뒤척입니다.

뒤척이기를 사용하는 자세에서는 일반 MotionTime 설정을 사용할 수 없습니다. Virtual Love의 수록 포즈에는 뒤척이기용 옆으로 눕는 애니메이션이 포함되어 있지 않으므로, 사용하려면 해당하는 모션을 준비하세요.

파라미터 사용량

필요 없는 기능을 끄면 ExpressionParameters 사용량을 줄일 수 있습니다.

포즈 확인과 조정

포즈 탭의 각 포즈에 있는 미리보기로 Scene에 자세를 표시할 수 있습니다. 애니메이션 조정을 열면 미리 보면서 몸의 방향과 관절을 조정하고 저장할 수 있습니다.

수록 포즈는 こよりLab의 あのん（Anon）을 기준으로 제작했습니다. 체형과 의상에 맞춰 상대와 닿는 위치 등을 조정하세요.

아바타 설정의 아바타별 보정 사용으로 기준 아바타와의 초기 관절 각도·비틀림 차이를 보정할 수 있습니다. 무릎이 반대로 꺾이지 않게 하기를 켜면 무릎이 거꾸로 꺾이는 것을 줄일 수 있습니다. 상세 설정을 열면 최소 무릎 굽힘(도)을 조절할 수 있습니다. 보정을 켠 상태의 모습도 미리보기로 확인하세요.

포즈 이름 검색, 여러 애니메이션 추가, 순서 변경도 포즈 탭에서 할 수 있습니다. 필요 없는 포즈는 비활성화하거나 삭제하세요.

간단 미리보기는 MA·NDMF 빌드를 실행하지 않으므로, 의상과 다른 기믹을 포함한 최종 상태는 아바타 빌드 후에도 확인하세요.

포즈 아이콘 이미지

기능의 포즈 아이콘 생성을 켜면 게임 내 메뉴에 자세 이미지를 넣을 수 있습니다. 이미지 생성만큼 빌드 시간이 늘어납니다. 용량을 줄이려면 아이콘 용량 줄이기를 켜세요. Android에서는 포즈 아이콘을 생성하지 않습니다.

프리셋

아바타 설정 맨 아래에서 프리셋을 선택할 수 있습니다. 이 프리셋 적용은 현재 포즈 설정을 덮어쓰므로 조정한 내용을 저장한 뒤 전환하세요.

애니메이션 조정 기능으로 만든 조정 애니메이션 파일과 그 파일을 설정한 프리셋은 Unisaki Studio의 개별 허락 없이 배포·판매할 수 있습니다. 직접 만든 아바타용 조정 데이터를 공유하는 등의 용도로 활용해 주세요.

프리빌드

프리빌드 업데이트로 메뉴와 애니메이션의 생성 결과를 저장하면 아바타 빌드 시 재사용하여 처리를 빠르게 할 수 있습니다. 프리빌드를 하지 않아도 일반 빌드 시 필요한 데이터를 생성합니다.

포즈나 기능을 변경했다면 Inspector의 설정 확인을 살펴보고, 프리빌드를 사용 중이라면 업데이트하세요. 경고 표시를 숨겨도 생성 결과는 업데이트되지 않습니다.

선물에 관하여

직접 사용하지 않는 경우 남성용과 여성용 중 하나를 파트너에게 선물할 수 있습니다. 선물받은 분은 선물해 준 분과만 함께 사용할 수 있습니다.

사용 시 주의 사항

  • 이 상품은 장난 목적으로 제작되었습니다. 괴롭힘 행위에는 사용하지 마세요.
  • VRChat 이용 약관과 매너를 지켜 사용하세요.
  • 풀바디 트래킹 중의 자세 고정은 지원하지 않습니다.
  • 아바타의 체형·의상·개조 내용에 따라 수동 조정이 필요할 수 있습니다.
  • 자세를 바꾸는 다른 기믹과 함께 사용할 때는 고정과 자세 전환의 동작을 확인하세요. 아바타 설정 > 다른 도구와 트래킹 고정 통합에서 조정할 수 있는 경우가 있습니다.
  • 이 도구를 사용하여 발생한 불이익에 대해 제작자는 책임지지 않습니다.
