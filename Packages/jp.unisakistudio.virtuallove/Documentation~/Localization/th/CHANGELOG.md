### เพิ่ม

- แสดง Inspector เมนูติดตั้ง ข้อความแจ้งสิทธิ์ใช้งาน ชื่อท่าที่รวมมา และเมนู VRChat ที่สร้างขึ้นได้ 30 ภาษา
- รวมการเลือกภาษา Inspector และเมนูในเกมเป็นตัวเลือกเดียว เริ่มจากภาษาคอมพิวเตอร์ และใช้ตัวเลือกล่าสุดในโปรเจกต์อื่นของผู้ใช้ OS เดียวกันด้วย
- เปิด README และประวัติการอัปเดตตามภาษาที่เลือกได้
- เตรียมชื่อแสดงของท่าที่รวมมา 22 ท่าและชื่อเมนูหมวด 5 หมวดในแต่ละภาษา
- รองรับ Unisaki Posing System 3.2.0

### ความเข้ากันได้

- รักษาการตั้งค่าอวาตาร์เดิม ชื่อกำหนดเอง การอ้างอิงแอสเซ็ต ตัวระบุพารามิเตอร์ และวิธีเก็บสิทธิ์ใช้งาน

## [3.1.0] - 2026-11-07

- เพิ่มโหมดถ่ายภาพ เคลื่อนอวาตาร์ไปข้างหน้าหรือหมุนเพื่อปรับไปยังตำแหน่งที่ถ่ายภาพง่ายได้ และเลือกซิงค์ตำแหน่งกับทิศทางให้คนอื่นเห็น หรือตั้งให้แสดงศีรษะของคุณระหว่างถ่ายภาพได้
- เพิ่ม «ความสูงพื้น» ย้ายทั้งตัวรวมศีรษะขึ้นลงได้ ใช้แยกจาก «ความสูงเท้า» ซึ่งขยับฝั่งเท้าโดยรักษาตำแหน่งศีรษะ
- เพิ่มแอนิเมชันหายใจ เลือกความแรงสำหรับแต่ละหมวดท่าได้ และเพิ่มเมนูสำหรับหยุดและเริ่มหายใจอีกครั้งในเกมได้ รวมทั้งมีการตั้งค่าลดการโยกตัวมาตรฐานขณะอยู่นิ่งของ VRChat
- เพิ่มการตั้งค่าลดท่าผิดรูปที่เกิดจากทิศทางศีรษะต่างกันเมื่อปลดล็อกศีรษะ
- รองรับการแก้ไขเฉพาะอวาตาร์และการป้องกันเข่างอกลับด้าน แก้ไขความต่างของข้อต่อจาก Anon ซึ่งเป็นอวาตาร์อ้างอิงในการสร้าง และปรับท่าให้เข้ากับอวาตาร์ได้
- เลือกฟังก์ชันที่ต้องการใน Inspector และตรวจปริมาณการใช้พารามิเตอร์ได้แล้ว
- ใช้การค้นหา การเพิ่มพร้อมกัน การเรียงลำดับในรายการท่า และตัวอย่างอย่างง่ายใน Scene ได้
- ติดตั้งได้จากเมนูคลิกขวาของอวาตาร์ด้วย «Unisaki Studio > เพิ่ม Virtual Love (ชาย)» หรือ «Unisaki Studio > เพิ่ม Virtual Love (หญิง)» หลังเพิ่มแล้วเลือกฟังก์ชันใน Inspector
- ต้องใช้ Unisaki Posing System 3.1.0
