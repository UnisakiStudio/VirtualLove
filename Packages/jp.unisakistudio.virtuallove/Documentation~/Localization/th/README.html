Virtual Love

เครื่องมือสำหรับอวาตาร์ VRChat ที่ให้คุณโพสท่าคู่กับอีกฝ่ายได้ทั้งในการติดตาม 3 จุดและโหมดเดสก์ท็อป มีท่าสำหรับฝ่ายชายและฝ่ายหญิงฝ่ายละ 22 ท่า รวมทั้งหมด 44 ท่า และยังทำท่ายืนฉีกขาแนวตั้งกับชาเลนจ์ Jack-O ได้ด้วย

README นี้สำหรับ v3.2.0 ที่อยู่ระหว่างพัฒนา ยังไม่กำหนดวันเผยแพร่อย่างเป็นทางการ ตรวจเวอร์ชันที่ติดตั้งได้ที่ด้านบนของ Inspector

ภาษาที่แสดงและเอกสารออฟไลน์

เลือกภาษาที่ «Language / 言語» ด้านบนสุดของ Inspector ตัวเลือกเดียวใช้กับทั้ง Inspector และเมนู VRChat ที่สร้างขึ้น ต้องอัปโหลดอวาตาร์ใหม่เพื่อเปลี่ยนภาษาในเกม

หากยังไม่เลือกจะใช้ภาษาของคอมพิวเตอร์ และใช้ภาษาอังกฤษเมื่อไม่รองรับภาษานั้น รองรับ Windows, macOS และ Linux ตัวเลือกล่าสุดจะบันทึกใน EditorPrefs และใช้ในโปรเจกต์อื่นของผู้ใช้ OS เดียวกันบนคอมพิวเตอร์นี้ด้วย เครื่องมือโพสท่าทั้งหมดและอวาตาร์ทุกตัวใช้ภาษาเดียวกัน การเปลี่ยนภาษาใน Inspector ของเครื่องมือใดก็ตามจะอัปเดตค่าที่ใช้ร่วมกัน โดยไม่ใช้ตัวเลือกภาษาเฉพาะอวาตาร์ ไม่ซิงค์ไปยังคอมพิวเตอร์อื่น และไม่เปลี่ยนวิธีเก็บสิทธิ์ใช้งาน ปุ่มภาษาจะแสดงเฉพาะในการยืนยันการติดตั้งครั้งแรกเมื่อยังไม่ได้บันทึกภาษา หลังจากนั้นให้เปลี่ยนภาษาใน Inspector

เลือก README และประวัติการอัปเดตได้จากรายการภาษาที่ให้มา «คู่มือ» และ «ดูประวัติการอัปเดต» ใน Inspector ก็เปิดตามภาษาที่เลือกเช่นกัน ชื่อท่าที่รวมมาและชื่อหมวดของเมนูในเกมก็แสดงตามภาษาที่เลือกด้วย ส่วนข้อกำหนดการใช้งานยังคงแนบฉบับภาษาญี่ปุ่นมาให้ตามเดิม

วิธีติดตั้ง

  1. นำเข้า «VirtualLove_Boy.unitypackage» หรือ «VirtualLove_Girl.unitypackage» ที่อยู่ในไฟล์ที่ซื้อมาสู่ Unity
  2. เมื่อลงทะเบียนแหล่งแจกจ่ายแพ็กเกจแล้ว จะเพิ่ม Virtual Love ในโปรเจกต์ที่ใช้ได้จาก VCC หรือ ALCOM ต้องใช้ Unisaki Posing System 3.2.0
  3. คลิกขวาที่อวาตาร์ที่ต้องการติดตั้งใน Hierarchy แล้วเลือก «Unisaki Studio > เพิ่ม Virtual Love (ชาย)» หรือ «Unisaki Studio > เพิ่ม Virtual Love (หญิง)»
  4. เลือก «三点だいしゅき(男)» หรือ «三点だいしゅき(女)» ที่เพิ่มเข้ามาในอวาตาร์ แล้วตั้งค่าฟังก์ชันและท่าที่จะใช้ใน Inspector
  5. ตรวจท่าด้วยตัวอย่าง แล้วอัปโหลดอวาตาร์ตามปกติ

ต้องใช้ Unity 2022.3, VRChat Avatars SDK 3.10.4 ขึ้นไป, Modular Avatar สาย 1.x ตั้งแต่ 1.15.1 และ NDMF สาย 1.x ตั้งแต่ 1.14.0 ให้อัปเดตแพ็กเกจที่จำเป็นพร้อมกันผ่าน VCC หรือ ALCOM

อัปเดตจากเวอร์ชันก่อน

อัปเดตสินค้านี้พร้อม Unisaki Posing System การตั้งค่าเครื่องมือที่วางไว้จะคงเดิม ตรวจฟังก์ชันและการใช้ ExpressionParameters ใน Inspector หากเคยใช้พรีบิลด์ ให้กด «อัปเดตพรีบิลด์» ก่อนอัปโหลดใหม่

ตำแหน่งตั้งค่า

แท็บการตั้งค่าหลัก
ฟังก์ชันเพิ่มเมนูในเกม โหมดถ่ายภาพ หายใจ ภาพไอคอน และตรวจปริมาณการใช้พารามิเตอร์
ท่าท่าที่ใช้ ค้นหา เพิ่ม เรียงลำดับ ตัวอย่าง และปรับแอนิเมชัน
ตั้งค่าอวาตาร์การแก้ไขร่างกาย นำเข้าท่าเดิมหรือการเคลื่อนไหวที่ทำเอง และพรีเซ็ต

เปิดฟังก์ชันที่ต้องการก่อนอัปโหลด รายการที่มี «เปิดการตั้งค่า» จะแสดงการตั้งค่าโดยละเอียดไว้ด้านล่างได้

การควบคุมพื้นฐานในเกม

เปิดเมนู Expressions แล้วเลือกท่าของ Virtual Love ให้ฝ่ายชายและฝ่ายหญิงเลือกท่าที่เข้าคู่กัน แล้วปรับตำแหน่งและทิศทางให้ตรงกับอีกฝ่าย

สลับการล็อกศีรษะ แขน และเท้า เพื่อเลือกส่วนที่ต้องการให้เคลื่อนตามการติดตามได้ เมื่อใช้ล็อกเท้า คุณขยับศีรษะได้โดยที่ท่าฝั่งเท้ายังคงเดิม หากต้องการกลับซ้ายขวาหรือปรับความสูงของท่า ให้เปิดฟังก์ชันที่เกี่ยวข้องใน Unity ไว้ก่อน

โหมดถ่ายภาพ

ย้ายอวาตาร์ของคุณไปยังตำแหน่งที่มองเห็นได้ ปรับทิศทาง แล้วถ่ายภาพได้

  1. เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > โหมดถ่ายภาพ» ใน Unity
  2. เปิด «โหมดถ่ายภาพ» ใน VRChat แล้วเลือกท่าที่ต้องการที่ «เลือกท่า»
  3. ใช้ «ระยะ» เคลื่อนอวาตาร์ไปข้างหน้าได้สูงสุด 3m เมื่อระยะมากกว่า 0 อวาตาร์จะหันมาหาคุณ
  4. หมุนด้วย «ทิศทาง» เมื่อได้ตำแหน่งแล้วให้เปิด «ล็อกเท้า» ตามต้องการ ตอนเริ่มจะไม่ล็อกเท้าให้อัตโนมัติ จึงปรับตำแหน่งก่อนล็อกได้
  5. เมื่อถ่ายเสร็จให้กด «จบการถ่ายภาพ» ระยะและทิศทางจะกลับคืน และปลดล็อกเท้า

หากเพิ่ม «ปิดท่ามือ» ไว้ในเมนู จะสลับรูปมือได้แม้อยู่ในโหมดถ่ายภาพ

หากเปลี่ยนตำแหน่งและทิศทางเฉพาะบนหน้าจอของคุณ จะไม่ใช้พารามิเตอร์ซิงค์ของโหมดถ่ายภาพ หากต้องการให้คนอื่นเห็นตำแหน่งและทิศทางเดียวกันด้วย ให้เปิด «ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก > ซิงค์โหมดถ่ายภาพ» ใน Unity

หากศีรษะของคุณหายไปเมื่อเข้าใกล้จนถ่ายภาพได้ยาก ให้เปิด «แสดงศีรษะในโหมดถ่ายภาพ» มีผลกับหน้าจอของคุณระหว่างถ่ายภาพ และกลับสู่การแสดงปกติเมื่อจบ

ความสูงเท้าและความสูงพื้น

เมื่อเปิดรายการที่ต้องการใน «ฟังก์ชัน > ฟังก์ชันเมนู» ของ Unity รายการนั้นจะถูกเพิ่มในเมนู «ตั้งค่า» ของ VRChat

  • ความสูงเท้า: ปรับความสูงฝั่งเท้าโดยรักษาตำแหน่งศีรษะ ใช้เมื่อเท้าจมพื้นหรือลอยจากพื้น หรือเมื่อต้องการปรับความสูงให้ตรงกับอีกฝ่าย
  • ความสูงพื้น: ย้ายทั้งตัวรวมศีรษะขึ้นลง 50% คือความสูงเดิม, 0% คือต่ำลง 3m, 100% คือสูงขึ้น 3m หากต้องการคืนค่าเดิมให้ปรับกลับมาใกล้ 50%

ใช้ร่วมกับโหมดถ่ายภาพเพื่อปรับความสูง ระยะ และทิศทางของอวาตาร์ได้ การเคลื่อนที่และการหมุนของโหมดถ่ายภาพกับความสูงพื้นยังแก้ไขการเคลื่อนไหวมาตรฐานและการเคลื่อนไหวกำหนดเองขณะที่ไม่ได้เลือกท่าด้วย ส่วนมุมมองใน VRChat และการทำงานหลังแทนที่การเคลื่อนไหวมาตรฐาน โปรดตรวจในการใช้งานจริง

กลับซ้ายขวาและปิดท่ามือ

  • กลับซ้ายขวา: เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > กลับซ้ายขวา» แล้วสลับซ้ายขวาของท่าจากเมนู VRChat
  • ปิดท่ามือ: เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > ปิดท่ามือ» เมื่อเปิดใช้ใน VRChat จะคงรูปนิ้วที่ตั้งไว้ในท่าได้แม้ขณะกำคอนโทรลเลอร์

หายใจ

  1. เปิด «ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก > เพิ่มแอนิเมชันหายใจ»
  2. จาก «เปิดการตั้งค่า» ให้เลือก «ไม่มี, เบา, กลาง, แรง, เร็ว, กำหนดเอง» สำหรับแต่ละหมวดท่า ปรับความแรงในหมวดที่ตรงกับท่าของ Virtual Love ส่วน «กำหนดเอง» ใช้กำหนดแอนิเมชันหายใจที่คุณเตรียมเองได้
  3. หากต้องการหยุดและเริ่มหายใจอีกครั้งในเกมด้วย ให้เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > หายใจ» ด้วย ใน VRChat ใช้ «หายใจ» สลับ ON/OFF

เมื่อเปิด «ปิดการโยกตัวเริ่มต้นของ VRChat» จะลดการโยกตัวมาตรฐานที่ใส่ให้อัตโนมัติขณะอยู่นิ่งได้ การหายใจที่ตั้งไว้ในเครื่องมือท่ายังใช้ได้ตามเดิม

ลดท่าผิดรูปจากการหมุนศีรษะ

เปิด «ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก > ลดท่าผิดรูปจากการหมุนศีรษะ» ใช้เมื่อปลดล็อกศีรษะแล้วท่าของร่างกายผิดรูปเพราะทิศทางศีรษะต่างจากท่าเดิม

พลิกตัว

พลิกตัวเป็นฟังก์ชันที่ใช้โดยเตรียมท่านอนที่รองรับและแอนิเมชันด้านข้างไว้

  1. เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > พลิกตัว»
  2. ใน «ท่า» เปิด «รายละเอียด» ของท่าที่จะใช้ แล้วเปิด «เปิดพลิกตัว»
  3. กำหนดแอนิเมชันที่ตรงกันใน «ท่าพลิกตัวด้านข้าง» และปรับ «ความแรงการแก้ไขพื้น» ตามต้องการ
  4. เลือกท่าที่รองรับใน VRChat ปลดล็อกศีรษะ แล้วเปิด «พลิกตัว» เมื่อเอียงศีรษะไปทางซ้ายหรือขวาจะพลิกตัว

ท่าที่ใช้พลิกตัวจะใช้การตั้งค่า MotionTime ปกติไม่ได้ ท่าที่รวมมาใน Virtual Love ไม่มีแอนิเมชันด้านข้างสำหรับพลิกตัว หากจะใช้ให้เตรียมการเคลื่อนไหวที่รองรับเอง

ปิดฟังก์ชันที่ไม่จำเป็นเพื่อลดการใช้ ExpressionParameters ได้

นอกจากนี้ยังมีปริมาณการใช้ของการเลือกท่าและส่วนอื่นเพิ่มเข้ามา ตรวจยอดรวมได้ใน Inspector เมื่อใช้ฟังก์ชันร่วมในเครื่องมือท่าหลายตัว ส่วนที่ใช้ร่วมกันจะไม่นับซ้ำ ปริมาณการใช้ของเสื้อผ้าและเครื่องมืออื่นไม่รวมอยู่ในยอดรวมนี้

ตรวจและปรับท่า

ใช้ «ตัวอย่าง» ของแต่ละท่าใน «ท่า» เพื่อแสดงท่าใน Scene เมื่อเปิด «ปรับแอนิเมชัน» จะปรับทิศทางของร่างกายและข้อต่อขณะดูตัวอย่าง แล้วบันทึกได้

ท่าที่รวมมาสร้างโดยอิงจาก «あのん（Anon）» ของ こよりLab โปรดปรับตำแหน่งที่สัมผัสกับอีกฝ่ายและส่วนอื่น ๆ ให้เข้ากับรูปร่างและเสื้อผ้า

«ใช้การแก้ไขเฉพาะอวาตาร์» ใน «ตั้งค่าอวาตาร์» ช่วยแก้ไขความต่างของมุมข้อต่อเริ่มต้นและการบิดเมื่อเทียบกับอวาตาร์อ้างอิง ส่วน «ป้องกันเข่างอกลับด้าน» ช่วยลดการงอเข่ากลับด้าน เมื่อเปิดการตั้งค่าโดยละเอียดจะปรับ «มุมงอเข่าต่ำสุด (องศา)» ได้ โปรดตรวจลักษณะขณะเปิดการแก้ไขด้วยตัวอย่างเช่นกัน

การค้นหาชื่อท่า การเพิ่มแอนิเมชันหลายรายการ และการเปลี่ยนลำดับก็ทำได้ใน «ท่า» เช่นกัน ท่าที่ไม่ต้องการให้ปิดใช้หรือลบออก

ตัวอย่างอย่างง่ายไม่รันการบิลด์ของ MA และ NDMF จึงควรตรวจผลลัพธ์สุดท้ายที่รวมเสื้อผ้าและเครื่องมืออื่นหลังบิลด์อวาตาร์ด้วย

ภาพไอคอนของท่า

เมื่อเปิด «สร้างไอคอนท่า» ใน «ฟังก์ชัน» จะใส่ภาพท่าในเมนูในเกมได้ การบิลด์จะใช้เวลาเพิ่มตามการสร้างภาพ หากต้องการลดขนาด ให้เปิด «ลดขนาดไอคอน» ไม่สร้างไอคอนท่าสำหรับ Android

พรีเซ็ต

เลือกพรีเซ็ตได้ที่ล่างสุดของ «ตั้งค่าอวาตาร์» คำสั่ง «ใช้พรีเซ็ตนี้» จะแทนที่การตั้งค่าท่าปัจจุบัน จึงควรบันทึกสิ่งที่ปรับไว้ก่อนเปลี่ยน

ไฟล์แอนิเมชันปรับแต่งที่สร้างด้วยฟังก์ชันปรับแอนิเมชัน และพรีเซ็ตที่ตั้งไฟล์เหล่านั้นไว้ สามารถแจกจ่ายหรือขายได้โดยไม่ต้องขออนุญาตจาก Unisaki Studio เป็นรายกรณี ใช้เพื่อแบ่งปันข้อมูลปรับแต่งสำหรับอวาตาร์ที่คุณสร้างเองและอื่น ๆ ได้

พรีบิลด์

เมื่อบันทึกผลการสร้างเมนูและแอนิเมชันด้วย «อัปเดตพรีบิลด์» จะนำกลับมาใช้ตอนบิลด์อวาตาร์เพื่อให้ประมวลผลเร็วขึ้นได้ แม้ไม่มีพรีบิลด์ การบิลด์ปกติก็สร้างข้อมูลที่จำเป็น

เมื่อเปลี่ยนท่าหรือฟังก์ชัน ให้ดู «ตรวจสอบการตั้งค่า» ใน Inspector และอัปเดตหากใช้พรีบิลด์อยู่ การซ่อนคำเตือนไม่ได้อัปเดตผลที่สร้างไว้

เกี่ยวกับการมอบเป็นของขวัญ

หากไม่ได้ใช้เอง คุณมอบฉบับสำหรับฝ่ายชายหรือฝ่ายหญิงอย่างใดอย่างหนึ่งให้คู่รักของคุณเป็นของขวัญได้ ผู้ที่ได้รับของขวัญใช้ได้เฉพาะกับผู้ที่มอบให้เท่านั้น

ข้อควรทราบในการใช้งาน

  • สินค้านี้สร้างขึ้นเพื่อความขบขัน โปรดงดใช้เพื่อการคุกคามผู้อื่น
  • โปรดใช้งานโดยปฏิบัติตามข้อกำหนดการใช้งานและมารยาทของ VRChat
  • ไม่รองรับการล็อกท่าขณะใช้ฟูลบอดี้แทร็กกิง
  • อาจต้องปรับด้วยตนเอง ขึ้นอยู่กับรูปร่าง เสื้อผ้า และการดัดแปลงของอวาตาร์
  • หากใช้ร่วมกับเครื่องมือเปลี่ยนท่าอื่น ให้ตรวจการทำงานของการล็อกและการสลับท่า บางกรณีปรับได้ที่ «ตั้งค่าอวาตาร์ > รวมการล็อกการติดตามกับเครื่องมืออื่น»
  • ผู้สร้างไม่รับผิดชอบต่อความเสียหายใด ๆ ที่เกิดจากการใช้เครื่องมือนี้

ข้อกำหนดการใช้งาน

โปรดใช้สินค้านี้หลังจากยอมรับข้อกำหนดการใช้งานที่จัดทำด้วยระบบสิทธิ์ใช้งาน VN3 แล้ว
