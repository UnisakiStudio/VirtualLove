三点だいしゅきツール

3点トラッキングやデスクトップで、相手とペアになる姿勢を楽しめるVRChatアバター向けツールです。男女それぞれ22種類、合計44種類のポーズを収録しています。I字バランスやJackOチャレンジもできます。

このREADMEは開発中のv3.2.0向けです。正式リリース日は未定です。導入済みのバージョンはInspector上部で確認できます。

表示言語とオフライン文書

Inspector最上部の「Language / 言語」で表示言語を選びます。一つの選択がInspectorと生成するVRChatメニューの両方に適用されます。ゲーム内の表示を変更するにはアバターを再アップロードしてください。

未選択の場合はパソコンの言語を使い、対応していない言語では英語を使います。Windows・macOS・Linuxに対応します。最後に選んだ言語はEditorPrefsに保存し、このパソコンの同じOSユーザーの別プロジェクトでも使用します。すべてのポーズツールとアバターで同じ言語を使用します。どのツールのInspectorで変更しても共通で反映され、アバターごとの言語指定は使用しません。他のパソコンには同期しません。ライセンスの保存方法は変更しません。 言語ボタンは言語が未選択の場合の最初の導入確認だけに表示されます。以後の言語変更はInspectorで行います。

READMEと変更履歴は同梱の言語一覧から選べます。Inspectorの「使い方」と「変更履歴」も選択言語に従います。収録ポーズの名前とゲーム内メニューの分類名も選択言語で表示します。利用規約は従来どおり日本語版を同梱しています。

導入方法

  1. 購入ファイルに同梱された「VirtualLove_Boy.unitypackage」または「VirtualLove_Girl.unitypackage」をUnityへインポートします。
  2. パッケージ配布元の登録後は、VCCやALCOMから使用するプロジェクトに「三点だいしゅきツール」を追加できます。ゆにさきポーズシステム 3.2.0 が必要です。
  3. Hierarchyで導入したいアバターを右クリックし、「ゆにさきスタジオ > 三点だいしゅきツール(男)追加」または「ゆにさきスタジオ > 三点だいしゅきツール(女)追加」を選びます。
  4. アバター内に追加された「三点だいしゅき(男)」または「三点だいしゅき(女)」を選び、Inspectorで使う機能とポーズを設定します。
  5. プレビューで姿勢を確認し、通常どおりアバターをアップロードします。

必要環境はUnity 2022.3、VRChat Avatars SDK 3.10.4以上、Modular Avatar 1.15.1以上の1.x系、NDMF 1.14.0以上の1.x系です。VCCやALCOMで必要なパッケージを併せて更新してください。

以前のバージョンから更新する場合

本商品と「ゆにさきポーズシステム」を併せて更新します。配置済みのツールの設定は引き継がれます。Inspectorで使用する機能とExpressionParametersの使用量を確認し、プレビルドを使っていた場合は「プレビルドを更新」を押してから再アップロードしてください。

ゲーム内での基本操作

Expressionsメニューを開き、三点だいしゅきツールのポーズを選びます。男女でペアになるポーズを選び、相手との位置や向きを合わせてください。

首・腕・足の固定を切り替えて、追従させたい部分を調整できます。足固定を使うと、足側の姿勢を保ちながら頭を動かせます。ポーズの左右や高さを調整したい場合は、Unityで対応する機能を有効にしておきます。

撮影モード

自分のアバターを見える位置へ動かし、向きを調整して撮影できます。

  1. Unityの「機能 > メニュー追加 > 撮影モード」をオンにします。
  2. VRChatで「撮影モード」を開き、「姿勢選択」で使いたいポーズを選びます。
  3. 「距離」でアバターを前方へ最大3m移動させます。距離を0より大きくすると、アバターはこちらを向きます。
  4. 「向き」で回転させ、位置が決まったら必要に応じて「足固定」をオンにします。開始時には自動で足固定されないので、固定前に位置を調整できます。
  5. 撮影が終わったら「撮影モードを終了」を押します。距離と向きが戻り、足固定が解除されます。

「ジェスチャー無効」をメニューに追加している場合は、撮影モード内でも手の形を切り替えられます。

自分の画面だけで位置と向きを変える場合、撮影モードの同期パラメーターは使いません。他の人にも同じ位置と向きを見せたい場合は、Unityの「機能 > 便利機能 > 撮影モードを同期する」をオンにします。

自分の頭が近づくと非表示になって撮影しづらい場合は、「撮影モード中は頭を非表示にしない」をオンにしてください。撮影中の自分の画面に適用され、終了後は通常の表示に戻ります。

足の高さ・床の高さ

Unityの「機能 > メニュー追加」で使いたい項目をオンにすると、VRChatの「設定」メニューに追加されます。

  • 足の高さ：頭の位置を保ちながら、足側の高さを調整します。足が床に埋まる・浮くときや、相手と高さを合わせたいときに使います。
  • 床の高さ：頭を含む身体全体を上下に移動します。50%が元の高さ、0%が3m下、100%が3m上です。元に戻すときは50%付近へ戻してください。

撮影モードと組み合わせて、アバターの高さ・距離・向きを調整できます。撮影モードの移動・回転と床の高さは、ポーズを選んでいないときの標準・独自モーションも補正対象です。VRChat内の視点や標準モーション置換後の挙動は、実機で確認してください。

左右反転・ジェスチャー無効

  • 左右反転：「機能 > メニュー追加 > 左右反転」をオンにし、VRChatのメニューでポーズの左右を切り替えます。
  • ジェスチャー無効：「機能 > メニュー追加 > ジェスチャー無効」をオンにします。VRChatで有効にすると、コントローラーを握ったときもポーズに設定された指の形を保てます。

呼吸

  1. 「機能 > 便利機能 > 呼吸の動きをつける」をオンにします。
  2. 「設定を開く」から、姿勢の分類ごとに「なし・弱・中・強・急・カスタム」を選びます。三点だいしゅきの姿勢に対応する分類で強さを調整してください。「カスタム」では自分で用意した呼吸アニメーションを指定できます。
  3. ゲーム内でも呼吸を止めたり再開したりしたい場合は、「機能 > メニュー追加 > 呼吸」もオンにします。VRChatでは「呼吸」でON/OFFを切り替えます。

「VRChat標準の揺れを止める」をオンにすると、待機中に自動で入る標準の身体の揺れを抑えられます。ポーズツールで設定した呼吸はそのまま使用できます。

首の向きによる姿勢崩れを抑える

「機能 > 便利機能 > 首の向きの違いによる姿勢崩れを抑制」をオンにします。首固定を解除したときに、元のポーズと首の向きが違うことで身体の姿勢が崩れる場合に使います。

寝返り

寝返りは、対応する寝姿勢と横向きのアニメーションを用意して使う機能です。

  1. 「機能 > メニュー追加 > 寝返り」をオンにします。
  2. 「ポーズ一覧」で使いたい姿勢の「詳細」を開き、「寝返りを使う」をオンにします。
  3. 「寝返り時の横向き」に対応するアニメーションを指定し、必要に応じて「接地補正の強さ」を調整します。
  4. VRChatで対応する姿勢を選び、首固定を解除して「寝返り」をオンにします。頭を左右に傾けると寝返りします。

寝返りを使う姿勢では、通常のMotionTime設定は使用できません。三点だいしゅきの収録ポーズには寝返り用の横向きアニメーションを同梱していないため、利用する場合は対応するモーションを用意してください。

パラメーター使用量

不要な機能をオフにすると、ExpressionParametersの使用量を抑えられます。

機能追加の使用量
左右反転1 bit
ジェスチャー無効1 bit
足の高さ8 bit
床の高さ8 bit
呼吸の動き0 bit
呼吸のゲーム内ON/OFF1 bit
撮影モード（自分の画面だけ）0 bit
撮影モードの同期16 bit
撮影中の頭の表示0 bit
首の向きによる姿勢崩れの抑制1 bit（寝返りと共用）
寝返り10 bit（うち1 bitを姿勢崩れの抑制と共用）

これらに姿勢選択などの使用量が加わります。合計はInspectorで確認してください。複数のポーズツールで共通機能を使う場合、共用分は重複して数えません。衣装など、ほかのギミックの使用量はこの合計に含まれません。

ポーズの確認と調整

「ポーズ一覧」の各ポーズにある「プレビュー」で、Sceneに姿勢を表示できます。「アニメーション調整」を開くと、プレビューしながら身体の向きや関節を調整して保存できます。

収録ポーズはこよりLab様の「あのん（Anon）」を基準に作成しています。体格や衣装に合わせて、相手と接する位置などを調整してください。

「アバター調整」の「アバター固有補正を使う」で、基準アバターとの初期関節角度やひねりの違いを補正できます。「膝が逆向きに曲がるのを防ぐ」では、膝の逆曲がりを抑えられます。詳しい設定を開くと「最低膝曲げ角度（°）」を調整できます。補正を有効にした状態の見た目もプレビューで確認してください。

ポーズ名の検索、複数アニメーションの追加、順番の変更も「ポーズ一覧」で行えます。不要なポーズは無効にするか削除してください。

簡易プレビューはMA・NDMFのビルド処理を実行しないため、衣装やほかのギミックを含めた最終状態はアバタービルド後にも確認してください。

ポーズのアイコン画像

「機能」の「ポーズアイコン生成」をオンにすると、ゲーム内メニューに姿勢の画像を付けられます。画像生成の分だけビルドに時間がかかります。容量を抑えたい場合は「アイコン画像の容量を減らす」をオンにしてください。Android向けではポーズアイコンを生成しません。

プリセット

「アバター調整」の一番下でプリセットを選べます。「このプリセットに変更する」は現在のポーズ設定を置き換えるので、調整済みの内容を保存してから切り替えてください。

アニメーション調整機能で作成した調整アニメーションファイルと、それを設定したプリセットは、ゆにさきスタジオへの個別の許諾なしで配布・販売できます。自作アバター向けの調整データの共有などにご利用ください。

プレビルド

「プレビルドを更新」でメニューやアニメーションの生成結果を保存すると、アバタービルド時に再利用して処理を速くできます。プレビルドなしでも、通常のビルド時に必要なデータを生成します。

ポーズや機能を変更したら、Inspectorの「設定の確認」を確認し、プレビルドを使用している場合は更新してください。警告の表示を消しても、生成結果は更新されません。

プレゼントについて

ご自身で使用しない場合、男女用どちらかをお砂糖さんにプレゼントできます。プレゼントされた方は、プレゼントしてくれた方とだけ使用できます。
