更新紀錄

[3.2.0] - 尚未發佈

新增

  • Inspector、安裝選單、授權提示、收錄姿勢名稱和產生的VRChat選單現已支援30種顯示語言。
  • 統一了Inspector和遊戲內選單的語言選擇。初始會使用電腦的語言，同一OS使用者的其他專案也會沿用最後的選擇。
  • 支援以所選語言開啟README和更新紀錄。
  • 為22種收錄姿勢的顯示名稱和5個分類選單的名稱準備了各語言版本。
  • 支援Unisaki Posing System 3.2.0。

相容性

  • 保留虛擬化身的現有設定、自訂名稱、資源參照、參數識別碼和授權儲存方式。

[3.1.0] - 2026-11-07

  • 新增拍照模式。可以將虛擬化身往前移動或旋轉，調整到方便拍照的位置。還可以選擇將位置和朝向同步給其他人，以及在拍照期間顯示自己的頭部。
  • 新增“地面高度”。可上下移動包含頭部在內的整個身體，並與維持頭部位置、移動腳部一側的“腳部高度”分開運用。
  • 新增呼吸動畫。可依姿勢分類選擇強度，還能加入在遊戲內暫停或恢復呼吸的選單。也可以使用抑制VRChat標準待機搖擺的設定。
  • 新增一項設定，用來減輕解除頭部固定後因頭部朝向不同而造成的姿勢變形。
  • 支援虛擬化身專屬修正和防止膝蓋反折。可修正與製作基準Anon之間的關節差異，並配合虛擬化身調整姿勢。
  • 現在可以在Inspector中選擇需要的功能，並確認參數用量。
  • 可在姿勢清單中使用搜尋、批次加入、調整順序，以及Scene中的簡易預覽。
  • 可從虛擬化身的右鍵選單透過“Unisaki Studio > 加入Virtual Love（男性）／加入Virtual Love（女性）”安裝。加入後的功能請在Inspector中選擇。
  • 需要Unisaki Posing System 3.1.0。
