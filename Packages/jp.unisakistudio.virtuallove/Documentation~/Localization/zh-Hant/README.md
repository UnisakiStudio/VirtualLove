# Virtual Love

這是一款VRChat虛擬化身專用的工具，即使使用3點追蹤或桌面模式，也能和對方擺出成對的姿勢。男性、女性各收錄22種，合計44種姿勢，還能做出站立一字馬和Jack-O挑戰。

本README面向開發中的v3.2.0。正式發佈日期尚未確定。已安裝的版本可在Inspector頂部查看。

## 顯示語言與離線文件

在Inspector最上方的“Language / 言語”中選擇顯示語言。同一項選擇會同時套用於Inspector和產生的VRChat選單。要更改遊戲內的顯示語言，請重新上傳虛擬化身。

未選擇語言時，使用電腦的語言；不支援該語言時使用英語。支援Windows、macOS和Linux。最後選擇的語言儲存在EditorPrefs中，同一臺電腦上同一個OS使用者的其他專案也會使用此設定。所有姿勢工具和虛擬化身都使用同一種語言。在任意工具的Inspector中變更語言，都會更新共用設定；不採用個別虛擬化身的語言選擇。語言設定不會同步到其他電腦。授權的儲存方式不變。 僅在尚未儲存語言時的首次安裝確認中顯示語言按鈕。之後請在Inspector中變更語言。

README和更新紀錄可從隨附的[語言清單](../index.html)選擇。Inspector中的“使用說明”和“更新紀錄”也會依照所選語言顯示。收錄姿勢的名稱和遊戲內選單的分類名稱，同樣會以所選語言顯示。使用條款則和以往一樣隨附日文版。

## 安裝方法

1. 將購買檔案中隨附的“VirtualLove_Boy.unitypackage”或“VirtualLove_Girl.unitypackage”匯入Unity。
2. 註冊套件來源後，即可透過VCC或ALCOM將Virtual Love加入要使用的專案。需要Unisaki Posing System 3.2.0。
3. 在Hierarchy中對要安裝的虛擬化身按一下滑鼠右鍵，選擇“Unisaki Studio > 加入Virtual Love（男性）”或“Unisaki Studio > 加入Virtual Love（女性）”。
4. 選取虛擬化身內新增的“三点だいしゅき(男)”或“三点だいしゅき(女)”，在Inspector中設定要使用的功能和姿勢。
5. 以預覽確認姿勢後，依一般流程上傳虛擬化身。

所需環境為Unity 2022.3、VRChat Avatars SDK 3.10.4或更高版本、Modular Avatar 1.15.1或更高版本的1.x系列，以及NDMF 1.14.0或更高版本的1.x系列。請通過VCC或ALCOM一同更新所需套件。

## 從舊版本更新

請將本商品和Unisaki Posing System一同更新。已放置工具的設定會繼承。請在Inspector確認啟用功能和ExpressionParameters用量；如果使用過預先建置，重新上傳前請按一下“更新預先建置”。

## 設定位置

| 頁籤 | 主要設定 |
| --- | --- |
| 功能 | 新增遊戲內選單、拍照模式、呼吸、圖示圖片、確認參數用量 |
| 姿勢 | 要使用的姿勢、搜尋、加入、調整順序、預覽、動畫調整 |
| 虛擬化身設定 | 身體修正、匯入原始姿勢或自製動作、預設 |

請先啟用需要的功能再上傳。帶有“開啟設定”的項目，可在其下方顯示詳細設定。

## 遊戲內基本操作

開啟Expressions選單，選擇Virtual Love的姿勢。請選擇男性與女性互相成對的姿勢，並和對方對齊位置與朝向。

切換頭部、手臂和雙腳的固定，即可調整要跟隨追蹤的部位。使用固定雙腳時，可以在維持腳部一側姿勢的同時移動頭部。若要將姿勢左右鏡像或調整高度，請事先在Unity中啟用對應的功能。

### 拍照模式

可以將自己的虛擬化身移到看得見的位置，調整朝向後拍照。

1. 在Unity中啟用“功能 > 選單功能 > 拍照模式”。
2. 在VRChat中開啟“拍照模式”，並在“選擇姿勢”中選擇要使用的姿勢。
3. 使用“距離”將虛擬化身往前移動，最遠可達3m。距離大於0時，虛擬化身會面向自己。
4. 使用“朝向”旋轉，位置確定後視需要啟用“固定雙腳”。開始時不會自動固定雙腳，因此可以在固定前調整位置。
5. 拍照結束後按下“結束拍照”。距離和朝向會復原，雙腳固定也會解除。

如果已將“停用手勢”加入選單，在拍照模式中也可以切換手型。

只在自己的畫面中改變位置和朝向時，不會使用拍照模式的同步參數。若希望其他人也看到相同的位置和朝向，請在Unity中啟用“功能 > 便利功能 > 同步拍照模式”。

如果自己的頭部靠近時會被隱藏而不好拍照，請啟用“拍照模式中保持頭部可見”。此設定只會套用到拍照期間自己的畫面，結束後會恢復一般顯示。

### 腳部高度與地面高度

在Unity的“功能 > 選單功能”中啟用要使用的項目後，這些項目會加入VRChat的“設定”選單。

- **腳部高度**：維持頭部位置，調整腳部一側的高度。適用於雙腳陷入地面或浮空時，或想和對方對齊高度時。
- **地面高度**：上下移動包含頭部在內的整個身體。50%為原始高度，0%為往下3m，100%為往上3m。要復原時，請調回50%附近。

搭配拍照模式使用，可以調整虛擬化身的高度、距離和朝向。拍照模式的移動、旋轉以及地面高度，也會修正未選擇姿勢時的標準動作和自訂動作。VRChat內的視角以及替換標準動作後的表現，請在實際環境中確認。

### 左右鏡像與停用手勢

- **左右鏡像**：啟用“功能 > 選單功能 > 左右鏡像”，再從VRChat的選單切換姿勢的左右。
- **停用手勢**：啟用“功能 > 選單功能 > 停用手勢”。在VRChat中開啟後，即使握住控制器，也能維持姿勢所設定的手指形狀。

### 呼吸

1. 啟用“功能 > 便利功能 > 啟用呼吸動畫”。
2. 透過“開啟設定”，為各個姿勢分類選擇“無、弱、中、強、急促、自訂”。請在對應Virtual Love姿勢的分類中調整強度。“自訂”可指定自己準備的呼吸動畫。
3. 如果也想在遊戲內暫停或恢復呼吸，請一併啟用“功能 > 選單功能 > 呼吸”。在VRChat中以“呼吸”切換ON/OFF。

啟用“關閉VRChat預設站立搖擺”後，可抑制待機時自動加入的標準身體搖擺。在姿勢工具中設定的呼吸仍可照常使用。

### 減輕頭部朝向造成的姿勢變形

啟用“功能 > 便利功能 > 減輕頭部旋轉造成的姿勢變形”。解除頭部固定後，若因頭部朝向與原始姿勢不同而使身體姿勢變形，請使用此功能。

### 翻身

翻身功能需要先準備對應的躺姿和側躺動畫才能使用。

1. 啟用“功能 > 選單功能 > 翻身”。
2. 在“姿勢”中開啟要使用的姿勢的“詳情”，並啟用“啟用翻身”。
3. 在“翻身側向姿勢”中指定對應的動畫，並視需要調整“接地修正強度”。
4. 在VRChat中選擇對應的姿勢，解除頭部固定後開啟“翻身”。將頭往左或往右傾斜即可翻身。

啟用翻身的姿勢無法使用一般的MotionTime設定。Virtual Love的收錄姿勢並未附帶翻身用的側躺動畫，若要使用，請自行準備對應的動作。

## 參數用量

關閉不需要的功能，可以降低ExpressionParameters的用量。

| 功能 | 額外用量 |
| --- | --- |
| 左右鏡像 | 1 bit |
| 停用手勢 | 1 bit |
| 腳部高度 | 8 bit |
| 地面高度 | 8 bit |
| 呼吸動畫 | 0 bit |
| 呼吸（遊戲內ON/OFF） | 1 bit |
| 拍照模式（僅自己的畫面） | 0 bit |
| 拍照模式同步 | 16 bit |
| 拍照期間顯示頭部 | 0 bit |
| 減輕頭部朝向造成的姿勢變形 | 1 bit（與翻身共用） |
| 翻身 | 10 bit（其中1 bit與姿勢變形抑制共用） |

除此之外，還要加上姿勢選擇等的用量。合計請在Inspector中確認。多個姿勢工具使用共用功能時，共用的部分不會重複計算。服裝等其他功能元件的用量不包含在此合計內。

## 姿勢的確認與調整

透過“姿勢”中各姿勢的“預覽”，可在Scene顯示姿勢。開啟“動畫調整”後，可以一邊預覽一邊調整身體朝向和關節，再加以儲存。

收錄姿勢是以こよりLab的“あのん（Anon）”為基準製作。請依照體型和服裝，調整與對方接觸的位置等。

透過“虛擬化身設定”中的“啟用虛擬化身專屬修正”，可以修正與基準虛擬化身在初始關節角度和扭轉上的差異。“防止膝蓋反折”可抑制膝蓋反向彎曲。開啟詳細設定後，可以調整“最小膝蓋彎曲角度（度）”。啟用修正後的外觀也請以預覽確認。

搜尋姿勢名稱、加入多個動畫、變更順序，也都在“姿勢”中進行。不需要的姿勢請停用或刪除。

簡易預覽不會執行MA、NDMF的建置處理，因此包含服裝和其他功能元件在內的最終狀態，也請在虛擬化身建置後確認。

### 姿勢圖示圖片

啟用“功能”中的“產生姿勢圖示”後，可為遊戲內選單加上姿勢圖片。產生圖片會增加建置時間。如需降低容量，請啟用“減少圖示容量”。Android版不會產生姿勢圖示。

### 預設

可以在“虛擬化身設定”的最下方選擇預設。“套用此預設”會取代目前的姿勢設定，因此切換前請先儲存已調整的內容。

使用動畫調整功能建立的調整動畫檔案，以及指定了這些檔案的預設，不必另外取得Unisaki Studio的許可，即可散布和販售。歡迎用來分享自製虛擬化身專用的調整資料等。

## 預先建置

透過“更新預先建置”儲存選單和動畫的產生結果後，建置虛擬化身時即可重複使用，加快處理速度。即使不使用預先建置，一般建置時也會產生所需資料。

變更姿勢或功能後，請查看Inspector中的“檢查設定”；如果正在使用預先建置，請加以更新。即使隱藏警告，產生結果也不會更新。
