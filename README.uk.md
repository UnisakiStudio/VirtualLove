# Virtual Love

Вихідний код і ресурси інструмента Virtual Love (三点だいしゅきツール), який продається на BOOTH.

## Посібник та історія змін

- [README: установлення, оновлення та налаштування](Packages/jp.unisakistudio.virtuallove/Documentation~/Localization/uk/README.md)
- [Історія змін](Packages/jp.unisakistudio.virtuallove/Documentation~/Localization/uk/CHANGELOG.md)
- [Сторінка товару на BOOTH](https://yunisaki.booth.pm/items/3641334)

Установлена версія відображається вгорі Inspector, коли ви вибираєте інструмент поз у Unity. Інструкції зібрано в README всередині пакета.

## Репозиторій та умови використання
